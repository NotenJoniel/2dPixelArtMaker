# 07. 品質検証・検収チェックリスト（QA Checklist）

アセットを `workspace/` から最終出力先 `assets/` へ納品する際は、**①自動バリデーション（機械的検査）**と**②視覚デザインレビュー（目視検査）**の両方をクリアしていることを確認します。

---

## 1. 自動検証項目（`validate_assets.py` ＆ `lint_character_style.py` 対応）

以下の2つのスクリプトを実行し、エラーが `0` 件であることを必須条件とします。

1. **フォーマット＆メタデータ検証**: `py tools/validate_assets.py assets --palette assets/palettes/master_palette.json`
2. **プロポーション＆造形スタイル検証（キャラ用）**: `py tools/lint_character_style.py <sprite.png> --size <size_preset> --taste <taste_preset>`

- [ ] **ファイル命名規則**: すべてのファイル・フォルダ名が英小文字・数字・アンダースコア（`snake_case`）のみで構成されているか。
- [ ] **画像フォーマット**: すべての画像が PNG（RGBA）であり、等倍（1x）解像度で保存されているか（`preview` 用の拡大画像が混入していないか）。
- [ ] **サイズ規格（`size_preset`）適合**: キャラ本体の実身長・横幅・色数が選択した規格（`fc_16x16` / `sfc_16x24` / `hd2d_18x32` / `high_32x56`）の定量範囲内に収まっているか（間延びしていないか）。
- [ ] **造形スタイル（`taste_preset`）適合**: `lint_character_style.py` において、首なし規格での首伸びエラー、左右100%対称のお椀・きのこ頭警告、内部の長い黒横線（輪切りボーダー）警告が出ていないか。
- [ ] **アルファチャンネル健全性**: 意図しない半透明ピクセル（Alpha `1`〜`254`）が存在しないか（半透明許可フラグがあるVFXや影パーツを除く）。
- [ ] **クロマキー抜き残しゼロ**: 作業用の背景色（`#FF00FF` 等）が1ピクセルも残っていないか。
- [ ] **マスターパレット準拠**: 使用されているすべての不透明ピクセルの色が、`assets/palettes/` 内の指定パレットに含まれているか。
- [ ] **リグメタデータ整合性（パーツ分割時）**:
  - `<asset_id>_meta.json` に記述されたすべてのパーツ画像および `variants` 画像が実在するか。
  - `part_mode == "canvas_aligned"` の場合、全パーツ画像の解像度が `canvas_size` と完全一致しているか。
  - `parent` 参照に存在しないパーツIDや循環参照が含まれていないか。
  - `pivot` や `origin` がキャンバス範囲内に収まっているか。
- [ ] **スプライトシート整合性**: `<sheet_name>.json` の `sheet_size` が実画像の幅・高さと一致し、各アニメーションの `(start_col + frames)` および `row` がシート範囲内に収まっているか。

## 2. 視覚・ドット絵品質チェック項目（プレビュー画像での目視確認）

`workspace/03_preview/` に出力した拡大プレビュー画像を確認し、以下の品質基準を満たしているかチェックします。

### 2.1 造形・世界観の一貫性
- [ ] **頭身とスケール感**: `docs/01_art_direction_and_world.md` で定めた基準タイルサイズ・頭身区分（`2頭身` / `2.5頭身` / `5頭身`）から逸脱していないか。
- [ ] **首なし直結チェック（2頭身・2.5頭身の場合）**: 頭と肩の間に不自然な「首（縦長の隙間）」が空いていないか。顎の下端がそのまま肩・襟の上端にしっかり乗っているか。
- [ ] **シルエット識別性**: キャラクター全体を真っ黒に塗りつぶした状態でも、「誰か／何のモンスターか／何の武器を持っているか」が判別できる特徴的なシルエットになっているか。
- [ ] **脱プログラマーアート**: 真四角や真円をそのまま置いただけの無機質な見た目になっていないか（曲線・テーパー・毛束や布のニュアンスが入っているか）。

### 2.2 ドット技術・シェーディング
- [ ] **ジャギー・二重角なし**: 輪郭線や曲線に不自然なL字の2px塊（Doubles）やガタつきが残っていないか。
- [ ] **光源の一致**: ハイライトと影の向きがプロジェクト共通光源と一致しているか（ピローシェーディング＝中心だけ明るい枕塗りになっていないか）。
- [ ] **背景とのコントラスト**: ゲーム内の床タイルや壁タイルの上に重ねて置いたとき、輪郭や足元が背景と同化して見づらくなっていないか。

### 2.3 パーツ分割・アニメーション品質（該当アセットのみ）
- [ ] **合成時の完全一致**: 全パーツを `z_index` 順に合成した際、隙間・座標ズレ・意図しない裏パーツのはみ出しがないか。
- [ ] **関節の回転耐性**: 腕（肩・肘）や脚（股・膝）、首を `±15°〜45°` 動かしたり `1〜2px` ずらした際に、関節の切れ目（透明な穴）が見えない十分な円形のりしろがあるか。
- [ ] **関節内の主線処理**: 素肌の肘・膝など、連続すべき部位の真ん中に不自然な黒主線が横切っていないか。
- [ ] **前髪下の描き込み**: `hair_front` や帽子を非表示にしたとき、`head_base` の額部分が途切れず描かれているか。
- [ ] **足元接地の安定**: アニメーション再生時にキャラクターの接地ライン（`origin`）がガタついたり浮いたりしていないか。
