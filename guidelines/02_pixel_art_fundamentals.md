# 02. ピクセルアート技術規約（日本式造形5原則・素体活用・4面描画ルール）

本プロジェクトでは「コードによるピクセル描画」を基本とします。**どのAIモデルがコードを書いても「プログラマーアート（野暮ったい図形の組み合わせ）」に陥らず、日本の商用2Dゲームのような魅力的なドット絵を安定再現する**ための必須技術規約を定めます。

---

## 1. 絶対厳守のフォーマット原則

1. **等倍（1x）ピクセル原則・Mixelsの禁止**: `assets/` 内の最終PNGはすべて `1ドット = 1px` の等倍で保存する。
2. **二値アルファ原則（半透明エッジの禁止）**: 通常スプライトのAlpha値は **`0`（完全透明）または `255`（完全不透明）の二値のみ**とする（VFXや丸影パーツとして仕様書で明示許可された場合を除く）。
3. **ASCIIマップの行幅完全一致**: `PixelCanvas.draw_ascii_map()` 使用時は、全行の文字数をキャンバス幅と完全一致させること（不一致時はツール側で即座に `ValueError` が発生する）。

---

## 2. 日本式2Dキャラクターを魅力的に見せる「造形5原則」

AIが白紙からキャラクターを描くと陥りやすい5つの「ダサ見えパターン」と、それを防ぐ定量ルールです（`tools/lint_character_style.py` により自動検査されます）。

### 原則①：髪型は「左右対称のお椀・きのこ型」を禁止し、非対称の毛束を作る
- **NG**: 頭頂部の真ん中だけポコッと出た左右対称の丸いヘルメット状。
- **OK**: 斜め分け・ツンツン跳ねる毛束（`cool`）や、片側に1〜2px飛び出す外ハネぴょこ毛（`cute`）を入れ、前髪の毛先を眉間や鉢巻の上に1〜2pxオーバーラップさせる。また**前髪内部の房分けに純黒主線（`outline_dark`）を使わず、髪の暗色（`wood_shadow` / `wood_deep` 等）で描く**ことで目元のノイズを防ぐ。

### 原則②：デフォルメ頭身（2〜3頭身）は「首0px直結」を徹底する
- **NG**: 顎の下に幅3〜4pxの細い首を描いて肩を下げる（ろくろ首現象）。
- **OK**: `fc_16x16`・`sfc_16x24`・`hd2d_18x32` では首の高さを **`0px`** とし、顎の4〜6pxラインのすぐ直下の行をそのまま肩・襟・Vネックの上端にする。この際、顎の肌色と胸元の肌色が縦にそのまま繋がって鼻が伸びて見えないよう、**顎直下の1行には必ず影色（`skin_warm_shadow`）または白インナー／襟色を挟む**。

### 原則③：コア胴体幅は「頭幅の半分（`6〜8px`）」に絞り、裾広がりを作る
- **NG**: 頭幅 `14px` に対して胸・腰も `12〜14px` ある四角い寸胴（ドラム缶体型）。
- **OK**: `sfc_16x24` では頭幅 `12px` に対し、両脇の腕を除いた**コア胴体幅を `6〜8px`** に引き締める。その上で拳・ハの字ブーツ（`cool`）や広がるマント（`cute`）で裾広がり（Aライン／Xライン）を作る。

### 原則④：短い胴体を「水平の黒線・横帯」で輪切りにしない
- **NG**: 襟・胸帯・ベルト・裾に水平な横一直線と黒主線を何本も引き、胴体をパンケーキ状に寸断する。
- **OK**: オープンベストの**Vネック**や**斜めの剣帯**など対角線の流れを取り入れ、ベルトや顎下の境界は黒主線ではなく**同系色の暗色シェード（色トレス／Sel-Out）**で繋ぐ。

### 原則⑤：頬の余白を最小（1px）にし、目のすぐ外側にもみあげを添える
- **NG**: 目の外側に肌色が3px以上余り、間の抜けたおまんじゅう顔になる。
- **OK**:
  - `cool` / `retro_classic` 主役（2.5頭身JRPG）: `[もみあげ1px][白目1px][瞳1px][鼻間肌2px][瞳1px][白目1px][もみあげ1px]`（顔内幅 `6px`、縦2px目）。※16-bit以上の主役・仲間を `1×2` 単色黒棒目にするとモブ兵士に見えるため必ず白目＋瞳で構成する。
  - `cute`（2頭身SD）: `[もみあげ1px][外頬1px][黒目1px][中央肌4px][黒目1px][外頬1px][もみあげ1px]`（顔内幅 `8px`、縦3px純黒目 ※目の下に青ドット等を足すと涙目に見えるため純黒でスッキリまとめる）。

### 原則⑥：兜の縁・帽子つば・鉢巻の「水平一直線バンド」禁止（主役・仲間キャラ）
- **NG**: 兜の下縁や魔法使い帽のリボン・つばを `gggggggggg` のように完全水平な1本線として引き、頭部を上下真っ二つに分断する（工事ヘルメットや三角コーンのように単調なモブ顔になる）。
- **OK**: 兜なら**眉間中央を1〜2px下げたV字ブリッジ（鼻当て）**や左右の頬当て段差をつけ、とんがり帽子なら**片側を1〜2px下げて斜めに被せる**か前髪を1px覗かせる（`lint_character_style.py` で水平一直線バンドを自動警告）。

### 原則⑦：斜め武器・背負い剣の「軸一致ルール」（T字折れ曲がりの厳禁）
- **NG（頻発ミス）**: 背中に背負った剣や槍の刀身（鞘）は右上〜左下の斜め45度（`/`）なのに、肩の上から出る**柄（グリップ）を真上（`|`）、鍔（クロスガード）を真横（`—`）の垂直T字（`⊥`）で描いてしまい、武器が肩元で折れ曲がって見える**現象。正面・横向きでも肩の横に垂直なT字レバーが生えているように見えてしまう。
- **OK（軸の完全一致）**:
  - 刀身が右上45度（`dx=+1, dy=-1` の階段 `/`）なら、**柄（グリップ）も必ず同じ右上45度の延長線上（`/`）に配置**し、**鍔（クロスガード）はそれに直交する左上〜右下45度（`\`）の階段ドット**で描くこと。
  - 正面（`down`）や横向き（`right` / `left`）で肩越しに柄と鍔だけが見える場合も、水平・垂直ではなく**必ず同じ45度傾きの斜めドット構造**（`tools/character_blueprints.py` の `sfc_16x24 / cool` 4方向素体を参照）で統一すること。

## 3. 素体ブループリント（`tools/character_blueprints.py`）の必須活用手順

別のAIモデルや新規セッションでも1発で正しい頭身・4面バランスを再現するため、キャラクター描画時は必ず以下の手順を踏みます。

1. **定量スペックと素体マップの取得**:
   ```powershell
   py tools/character_blueprints.py --info sfc_16x24 cool
   py tools/character_blueprints.py --show sfc_16x24 cool down
   ```
2. **素体からのカスタマイズ展開**:
   - 出力された検証済み素体の**「頭頂Y座標〜顎Y座標」「目のX/Y座標」「肩〜腰のコア幅」「足底接地Y座標」を固定アンカーとして維持**したまま、キャラクター固有の髪型・帽子・衣装・武器へと書き換える。
3. **4方向（`down`, `up`, `right`, `left`）展開時の鉄則**:
   - **高さの完全一致**: 4方向すべてで頭頂Y座標と足底接地Y座標を揃える。
   - **背面（`up`）の左右反転整合性**: 正面（`down`）で画面左（＝キャラの右肩）にあった剣の柄や非対称装飾は、背面（`up`）では**画面右**へ配置し、後頭部の髪と鉢巻結び目で顔を隠す。
   - **横向き（`right` / `left`）の視線と厚み**: 横顔の目は**「向いている前方側に瞳1px、後ろ側に白目1px」**を配置して視線を前へ飛ばす（FF6方式）。後頭部〜なびく鉢巻／髪で前後の奥行きを出し、手前の腕と前後の足を1〜2pxずらして立体的に立たせる。

## 4. ドット絵の基本4大NGチェック（ジャギー・枕塗り・バンディング・孤立点）

1. **L字の二重角（Doubles）除去**: 1px曲線の途中にL字の2px塊を作らない。
2. **ピローシェーディング禁止**: 外周内側を一周暗くして中心だけ明るくする枕塗りを避け、左上／真上光源に沿って非対称に塗る。
3. **バンディング回避**: 輪郭線と全く同じ長さの明暗ラインを平行に並べず、立体面に沿った塊（クラスター）で塗る。
4. **孤立ノイズドット排除**: 意図したハイライト点以外は2〜4px以上の色クラスターで構成する。
