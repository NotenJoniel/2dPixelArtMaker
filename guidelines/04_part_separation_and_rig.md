# 04. パーツ分け・レイヤー階層・ピボット規約

2Dキャラクターアセットにおいて、顔・体・手・足などをパーツ分け（モジュラー分割／カットアウト構造）することで、**骨格アニメーション、表情差分、武器・防具の着せ替え、コード上での柔軟なポーズ生成**が可能になります。

本ドキュメントでは、パーツ回転や差し替えを行っても破綻しないための分割粒度、関節の「のりしろ」設計、描画順（Z-Order）、ピボット（回転軸）の標準ルールを定めます。

---

## 1. 表現方式の選択基準（コマ打ち vs パーツ分割）

すべてのキャラクターを無理に細かく分割する必要はありません。サイズと用途に応じて以下の3段階から選択し、個別仕様書（`docs/characters/<id>.md`）に明記します。

| 方式 | 推奨キャンバス目安 | 構造と特徴 | 向いている対象 |
| :--- | :--- | :--- | :--- |
| **① 単一コマ打ち（Frame-by-Frame）** | `16x16` 〜 `32x32` px | パーツ分割せず1枚絵として各フレームを描画。1px単位の変形が自由。 | 小型雑魚モンスター、スライム等の不定形生物、2頭身ミニキャラ |
| **② 簡易パーツ分割（5〜8パーツ）** | `32x32` 〜 `48x48` px | `head`, `face`, `torso`, `arm_l/r`, `leg_l/r`, `weapon` 程度の大分類分割。 | 一般NPC、ザコ人型敵、軽快なドットアクションキャラ |
| **③ 標準多関節分割（14〜22パーツ）** | `48x48` 〜 `128x128` px | 上腕・前腕・手、太もも・すね・足、前髪・後ろ髪・目・口まで分離。 | 主人公、主要仲間キャラ、着せ替え対応キャラ、大型人型ボス |

---

## 2. 標準パーツIDと分割粒度（人型キャラクター基準）

**デフォルトの向き基準**: 横視点・斜め前視点では原則として **「画面右向き（Right-Facing）」** を基準ポーズとします。
- **`_l`（Left / 手前側）**: 右向きに立ったとき、カメラに近い手前側（左半身）の腕・脚。
- **`_r`（Right / 奥側）**: 右向きに立ったとき、体の向こう側に隠れる奥側（右半身）の腕・脚。
- 正面立ち（トップダウン南向き等）の場合は、キャラクター自身の左手・左足を `_l`、右手・右足を `_r` とします。

### 2.1 頭部・顔パーツ（Head & Face）
| 標準パーツID | 役割・含まれる部位 | 分割時のポイント |
| :--- | :--- | :--- |
| `hair_back` | 後ろ髪・ポニーテール・ロングヘア背面 | 胴体や首よりも奥（背面）に配置。揺れアニメをつけやすいよう独立させる。 |
| `head_base` | 顔の輪郭・肌・耳（前髪に隠れる額部分も塗っておく） | **重要**: 前髪を動かしてもハゲて見えないよう、頭頂部・額までベース肌や頭蓋シルエットを描き切る。 |
| `face_effect` | 赤面・青ざめ・汗などの感情オーバーレイ（任意） | `head_base` の直上、目や口の下または上に配置。 |
| `eyes` | 両目（白目・瞳・まつ毛） | `normal`, `blink`（閉じ）, `happy`, `angry`, `damage` 等の差分（`variants`）を用意する。 |
| `eyebrows` | 眉毛（小サイズでは `eyes` に統合可） | 1〜2px上下・傾きを変えるだけで喜怒哀楽が大きく変わる重要パーツ。 |
| `mouth` | 口 | `closed`, `open`, `smile`, `shout` 等の会話・アクション差分を用意する。 |
| `hair_front` | 前髪・サイドの垂れ髪・アホ毛 | `eyes` / `eyebrows` より手前に配置（眉毛だけ前髪の上に透けさせる表現も可）。 |
| `headgear` | 帽子・兜・リボン・角・髪飾り（任意） | 着脱や装備変更に対応する場合は `hair_front` とは別パーツにする。 |

### 2.2 胴体・背面パーツ（Torso & Back）
| 標準パーツID | 役割・含まれる部位 | 分割時のポイント |
| :--- | :--- | :--- |
| `back_attachment` | マント・翼・背負い鞘・バックパック（任意） | 最背面または `hair_back` のさらに奥に配置。 |
| `neck` | 首（中〜小サイズでは `torso_upper` に統合可） | 頭を上下前後に傾けた際に顎と胸の間が途切れないよう上下に長めに描く。 |
| `torso_lower` | 腰・骨盤・ベルト・スカート基部（Pelvis） | 下半身のルート（根元）または全身の基準親パーツになる。 |
| `torso_upper` | 胸・腹部・肩口（Chest） | 呼吸モーション（待機時に1px上下）だけで生命感が出るため、腰と分けると効果大。 |

### 2.3 腕・手・所持品パーツ（Arms, Hands & Held Items）
| 標準パーツID | 役割・含まれる部位 | 分割時のポイント |
| :--- | :--- | :--- |
| `arm_upper_l` / `_r` | 上腕（肩〜肘） | 肩の付け根を丸く描き、`torso_upper` に重ねる。 |
| `arm_lower_l` / `_r` | 前腕（肘〜手首）・籠手 | 肘の接続部を丸く描き、上腕と重ねる。 |
| `hand_l` / `_r` | 手首から先 | `fist`（握り）, `open`（開き）, `grip`（武器持ち）の差分を持つと汎用性が高い。 |
| `weapon_l` / `_r` | 剣・杖・銃・盾などの手持ち装備 | 原則として `hand` の子要素とし、グリップ位置にピボットを置く。手甲で持ち手を隠す場合は `hand_front` オーバーレイを使ってもよい。 |

### 2.4 脚・足パーツ（Legs & Feet）
| 標準パーツID | 役割・含まれる部位 | 分割時のポイント |
| :--- | :--- | :--- |
| `leg_upper_l` / `_r` | 太もも（股関節〜膝） | 股関節側を丸めて `torso_lower` の下に差し込む。 |
| `leg_lower_l` / `_r` | すね（膝〜足首）・ブーツ筒 | 膝の接続部を丸める。 |
| `foot_l` / `_r` | 足首から先・靴 | かかと〜くるぶし付近にピボットを置き、接地感を安定させる。 |

## 3. 最重要：関節の「のりしろ（Joint Overlap）」と主線処理ルール

パーツを単純に直線でぶつ切り（スライス）にすると、腕や脚を少しでも回転・移動させた瞬間に**三角形の隙間（割れ目）**が空いてしまいます。コードでパーツを別々に描画する際は、必ず以下の2ルールを適用します。

### 3.1 円形オーバーラップ（丸みのりしろ）の確保
関節の接続端は直線で切らず、**ピボット（回転中心）を中心とした半径 `r` ピクセルの半円状（丸み）にはみ出して塗り足す**構造にします。

```text
[NG: 直線で切断]                     [OK: ピボット中心の円形のりしろ]
  ┌────┐                               ┌────┐
  │上腕│                               │上腕│
  └────┘  ← 曲げると隙間が空く！       ╰─⊕─╯  ← ⊕(ピボット)中心に丸く描き足す
  ┌────┐                               ╭─⊕─╮  ← 下側パーツも丸く重ねる
  │前腕│                               │前腕│
  └────┘                               └────┘
```
- **重なり幅の目安**:
  - `32x32`〜`48x48` キャラ：ピボットから上下に各 **`2`〜`3` px** の重なり
  - `64x64`〜`128x128` キャラ：ピボットから上下に各 **`3`〜`6` px** の重なり

### 3.2 関節内部の主線（アウトライン）抜き処理
たとえば同じ肌色の「上腕」と「前腕」が重なる肘の内側まで黒い1pxアウトラインでぐるっと囲ってしまうと、腕を伸ばしたときに関節の真ん中に黒い横線が入って球体関節人形のように見えてしまいます。

- **異素材・服の切れ目（例: 半袖の袖口と素肌の腕、ブーツの履き口とズボン）**: 境界線があって自然なので、手前パーツの端まで主線を描いてよい。
- **同一素材・連続する部位（例: 素肌の上腕と前腕、同じ布の太ももとすね、首と顎の付け根）**: 重なり合う接続先端の2〜3px区間だけ**外周アウトラインを省略（ベース色または影色のまま開放）**し、両サイドの輪郭線だけが自然に繋がるように描画する。

## 4. 標準描画順（Z-Order）と親子階層（Parent-Child Hierarchy）

`z_index` は**数値が小さいほど奥（背面）、大きいほど手前（前面）**に描画します。将来的にマントやエフェクト・追加装飾を間に差し込めるよう、`10` 刻み（または `5` 刻み）で番号を振ります。

### 標準 Z-Order ＆ 親子関係テーブル（右向き3/4サイド基準）

| Z順 (`z_index`) | パーツID | 親パーツ (`parent`) | 備考 |
| :---: | :--- | :--- | :--- |
| `5` | `back_attachment` | `torso_upper` | マント背面・翼など最背面要素 |
| `10` | `hair_back` | `head_base` | 後ろ髪 |
| `15` | `arm_upper_r` | `torso_upper` | 奥側の上腕 |
| `18` | `arm_lower_r` | `arm_upper_r` | 奥側の前腕 |
| `20` | `weapon_r` | `hand_r` | 奥側の手に持つ装備（盾など） |
| `22` | `hand_r` | `arm_lower_r` | 奥側の手 |
| `25` | `leg_upper_r` | `torso_lower` | 奥側の太もも |
| `27` | `leg_lower_r` | `leg_upper_r` | 奥側のすね |
| `29` | `foot_r` | `leg_lower_r` | 奥側の足 |
| `35` | `torso_lower` | `null` (Root) | 腰・骨盤（全身のルート基準） |
| `40` | `leg_upper_l` | `torso_lower` | 手前側の太もも（スカート等の場合は腰と前後調整） |
| `42` | `leg_lower_l` | `leg_upper_l` | 手前側のすね |
| `44` | `foot_l` | `leg_lower_l` | 手前側の足 |
| `50` | `torso_upper` | `torso_lower` | 胸・上胴 |
| `55` | `neck` | `torso_upper` | 首 |
| `60` | `head_base` | `neck` (or `torso_upper`) | 顔輪郭・耳 |
| `62` | `face_effect` | `head_base` | 赤面・青ざめ等 |
| `65` | `mouth` | `head_base` | 口 |
| `68` | `eyes` | `head_base` | 目 |
| `70` | `eyebrows` | `head_base` | 眉 |
| `75` | `hair_front` | `head_base` | 前髪・横髪 |
| `78` | `headgear` | `head_base` | 帽子・兜・頭飾り |
| `85` | `arm_upper_l` | `torso_upper` | 手前側の上腕 |
| `88` | `arm_lower_l` | `arm_upper_l` | 手前側の前腕 |
| `90` | `weapon_l` | `hand_l` | 手前側の武器（握り手より奥か手前かは持ち方で調整） |
| `92` | `hand_l` | `arm_lower_l` | 手前側の手 |

## 5. パーツ画像の書き出し座標方式

エンジン非依存で扱いやすく、かつコード生成時の座標ズレ事故を防ぐため、以下の2モードを定義します（デフォルト推奨は **`canvas_aligned`**）。

1. **`canvas_aligned`（共通キャンバス方式 — 標準推奨）**
   - すべてのパーツPNGを、キャラクター全体と同じキャンバスサイズ（例: `64x64` px）の透過画像として、**デフォルト立ちポーズの正しい配置位置にそのまま書き出す**方式。
   - **利点**: 全パーツを `(0, 0)` 座標に `z_index` 順で重ねるだけで1pxの狂いもなく完成立ち絵になり、目視確認・衣装追加・表情差し替えが圧倒的に簡単になる。`<char_id>_meta.json` の `pivot` にはキャンバス左上 `(0, 0)` からの回転軸ピクセル座標 `[px, py]` を記録する。
2. **`trimmed`（最小矩形トリム方式 — テクスチャ容量最適化用）**
   - 透明余白を切り詰めた最小サイズで各パーツPNGを保存し、`<char_id>_meta.json` の `offset: [ox, oy]` にキャンバス上の配置左上座標、`pivot: [px, py]` にトリム画像内のローカル回転軸座標を記録する方式。
