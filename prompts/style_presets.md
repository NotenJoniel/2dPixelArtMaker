# スタイル別プリセット集（世界観・コード描画パラメータ対応表）

新規プロジェクトの立ち上げ時（`docs/01_art_direction_and_world.md` 作成時）や、AIエージェントに画風を指定する際にそのまま利用できる代表的なピクセルアートスタイルのプリセット定義です。

---

## Preset A: 16bit 王道アクションRPGスタイル（最も汎用・パーツ分割向き）

- **想定ジャンル**: 横スクロールアクション、メトロイドヴァニア、サイドビューRPG
- **推奨スペック**:
  - 仮想画面解像度: `480 x 270` px（1080pで整数4倍）
  - 基準タイルサイズ: `16 x 16` px
  - 標準人間キャンバス: `64 x 64` px（実身長 `42〜46` px、約 `3.5` 頭身）
  - 主線ルール: 濃紫黒（`#181425`）による1pxアウトライン（関節の連続部のみ主線省略）
  - 階調・光源: 3階調（光・ベース・1影）＋色相シフト必須、真上やや手前光源（左右反転対応）
- **コード描画時の造形指針**:
  - 頭部高さは約 `13〜14` px、目は縦 `3〜4` px × 横 `2` px で白目1列＋瞳＋白ハイライト1pxを入れ感情豊かに描く。
  - 手とブーツはやや大きめ（幅 `5〜7` px）に取り、アクション時のシルエットを強調する。

---

## Preset B: レトロ・トップダウン冒険RPGスタイル（見下ろし型・コンパクト）

- **想定ジャンル**: 見下ろし型RPG、ローグライク、牧場・生活シミュレーション
- **推奨スペック**:
  - 仮想画面解像度: `320 x 180` px（1080pで整数6倍）
  - 基準タイルサイズ: `16 x 16` px
  - 標準人間キャンバス: `24 x 24` または `32 x 32` px（実身長 `20〜24` px、約 `2` 頭身）
  - 方向パターン: 南（正面）・北（背面）・右（横、左は反転可）の3パターン（4方向対応）
  - 主線ルール: 濃色1pxアウトライン（タイル背景は主線なし）
  - 階調・光源: 2〜3階調、真上光源
- **コード描画時の造形指針**:
  - 小サイズのため多関節分割よりも「単一コマ打ち」または「頭＋体の2パーツ構成」を推奨。
  - 記号ドットマップ（ASCII Pixel Map）で1ピクセルずつ左右対称性と可愛らしい丸みを精密に設計する。

---

## Preset C: ダークファンタジー・ハイディテールスタイル（シリアス・重厚）

- **想定ジャンル**: ソウルライク2Dアクション、ダークゴシック探索、タクティカルRPG
- **推奨スペック**:
  - 仮想画面解像度: `640 x 360` px（1080pで整数3倍）
  - 基準タイルサイズ: `32 x 32` px
  - 標準人間キャンバス: `96 x 96` px（実身長 `64〜72` px、約 `5.5〜6` 頭身）
  - 主線ルール: 色トレス（各素材の最深影色による選択的アウトライン）
  - 階調・光源: 4階調（ハイライト・明ベース・暗ベース・深影）、彩度低め・明暗コントラスト強め
- **コード描画時の造形指針**:
  - 顔の目鼻は描き込みすぎず、兜のスリットや前髪の落ち影（Cast Shadow）で重厚な雰囲気を出す。
  - 金属鎧の鋭い1pxリムライト（縁の反射光）と、マントの深い影の対比を強調する。
