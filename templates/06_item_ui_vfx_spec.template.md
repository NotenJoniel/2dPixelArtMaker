## 1. アイテム・スキルアイコン仕様（`assets/items/`）

### 1.1 共通アイコン規格
| 項目 | 設定値 | 備考 |
| :--- | :--- | :--- |
| **標準アイコンキャンバス** | `[16 x 16]` または `[24 x 24]` px | インベントリ画面の表示サイズに統一 |
| **外周マージン** | 四辺 `1px` 以上の余白推奨 | 選択カーソル枠と重なっても潰れないようにする |
| **配置角度の統一** | 長物（剣・杖・弓）は **「左下＝柄、右上＝先端」の45度対角線配置** | 対角線を使うことで限られたピクセル数で最大限長くシャープに描ける |
| **アウトライン** | `outline_dark` (`#181425`) 1px囲み必須 | どのUI背景色の上でもくっきり視認できるようにする |

| アイコンID | 名称 | カテゴリ | サイズ | モチーフ・色指定 |
| :--- | :--- | :--- | :---: | :--- |

| `itm_sword_iron` | 鉄の片手剣 | 武器 | `16 x 16` | 45度配置、銀色の刃（`neutral`）、真鍮の鍔（`gold`）、革巻きの柄 |

## 3. エフェクト（VFX）スプライトシート仕様（`assets/vfx/`）

> **コード描画でのVFXのコツ**: エフェクトは原則として黒主線を使わず、「1フレーム目は純白（`#FFFFFF`）の強い閃光 → 中盤フレームで属性の明るい色へ広がり → 終盤フレームで暗い色へ変化しながら小さな粒（1〜2px）に千切れて消える」ように描くと非常に気持ちよいドットエフェクトになります。

| VFX ID | 用途 | セルサイズ | フレーム数 | FPS | 半透明許可 | 演出メモ |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| `vfx_slash_01` | 剣の斬撃軌跡 | `48 x 48` | `4` | `16` | 二値（不透明） | 三日月型の鋭い白弧 → 水色への色変化 → 粒子分解 |
| `vfx_hit_spark` | 攻撃ヒット火花 | `32 x 32` | `4` | `18` | 二値（不透明） | 中心から十字・斜め方向へ鋭く弾ける白〜黄のスパーク |
| `vfx_dust_jump` | ジャンプ・着地砂煙 | `32 x 16` | `5` | `12` | 二値（不透明） | 足元から左右に丸い煙玉が広がり、輪っか状に抜けて消える |
| `vfx_explosion_s` | 小型撃破爆発 | `32 x 32` | `6` | `14` | 二値（不透明） | 白閃光 → オレンジ火球 → 暗い煙への遷移 |
