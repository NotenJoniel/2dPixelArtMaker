## 2. 画面・グリッド・視点スペック（必須固定項目）

| パラメータ | 確定値 | 選択肢・備考 |
| :--- | :--- | :--- |
| **仮想画面解像度** | `[480 x 270]` px | 推奨: `320x180` (6倍) / `480x270` (4倍) / `640x360` (3倍) ※1080p整数倍対応 |

## 3. キャラクター頭身・サイズ区分基準

| サイズ区分 | 想定対象 | 標準キャンバスサイズ (px) | 実身長目安 (px) | 標準頭身 | 基本表現方式 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| **S（小型）** | 小動物・妖精・小型ザコ | `32 x 32` | `14 〜 22` | 1.5〜2頭身 | 単一コマ打ち |
| **M（標準人間）** | 主人公・仲間・一般NPC | `64 x 64` | `40 〜 48` | 3.5頭身 | 多関節パーツ分割（または簡易分割） |
| **L（大型）** | 重装騎士・中型モンスター | `96 x 96` | `64 〜 80` | 4〜5頭身 | 多関節パーツ分割 |
| **XL（ボス級）** | ドラゴン・巨大兵器ボス | `128 x 128` 以上 | `100+` | 自由 | 大型パーツ分割 |

## 4. 主線・光源・シェーディング規約

| 項目 | 確定ルール | 選択肢・補足 |
| :--- | :--- | :--- |
| **キャラ・動的物の主線** | `[濃色固定1px / 色トレス1px / 主線なし]` | 例: 最暗色 `#181425` による1pxアウトライン（関節内部のみ省略） |
| **背景・地形タイルの主線** | `[主線なし / 接触面のみ濃色]` | 例: 遠景は主線なし、踏める床の上端エッジのみ明暗強調 |
| **共通光源の方向** | `[真上やや手前 / 左上45度]` | 左右反転を使うアクションでは `真上やや手前` を推奨 |
| **基本塗りの階調数** | `[3階調（光・ベース・1影）]` | `2階調` / `3階調` / `4階調` |
| **ディザリング（網掛け）** | `[キャラ禁止・大型背景のみ可]` | 小〜中型キャラへの市松ディザリングはアニメ時のチラつき防止のため原則不可 |
| **半透明表現の可否** | `[原則不可（二値アルファ）]` | 例外: 足元の丸影（Alpha `100`）および魔法発光エフェクトのみ許可 |

## 5. デザイン上の特徴・共通モチーフメモ

- **シルエット方針**:
  - （例：全プレイアブルキャラに「風になびくパーツ（マフラー・リボン・外套のいずれか）」を1つ以上持たせ、移動時の気持ちよさを強調する）
- **デフォルメ方針**:
  - （例：手と足（靴）はリアル比率より1.3倍ほど大きめに描き、武器を持った際のポーズと接地感を強く見せる）
- **禁止・避ける表現**:
  - （例：現代的なプラスチック質感や蛍光ネオンカラーは遺跡の世界観に合わないため使用しない）
