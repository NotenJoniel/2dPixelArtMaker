## 1. パレット全体方針

| 項目 | 設定内容 | 記入例 |
| :--- | :--- | :--- |
| **マスターパレット名** | `[master_palette]` | 出力先: `assets/palettes/master_palette.json` |
| **総色数上限（目安）** | `[32色 〜 48色]` | 例: 共通基本32色 ＋ 属性エフェクト専用8色 |
| **1キャラあたりの推奨色数** | `[8色 〜 14色]` | 主線1色 ＋ 肌3色 ＋ 髪3色 ＋ メイン衣装3色 ＋ 差し色2〜3色 |
| **最暗色（基本アウトライン色）** | `[#181425]` | 純黒 `#000000` の代わりに用いる濃紫黒／濃紺黒 |
| **純白（ハイライト極値色）** | `[#FFFFFF]` | 瞳ハイライト・斬撃閃光・UI強調のみに限定使用 |
| **作業用クロマキー予約色** | `[#FF00FF]` | アセット本体の色としては絶対に使用しない予約色 |
| **色相シフト方針** | `光＝黄・暖色シフト / 影＝青紫・寒色シフト` | 単純な白黒混色ではなく色相をずらして彩度を保つ |

## 2. レイヤー別コントラスト設計（明度・彩度レンジ）

| レイヤー区分 | 明度レンジ目安 (0〜100%) | 彩度レンジ目安 | 備考 |
| :--- | :---: | :---: | :--- |
| **遠景（Sky / Far BG）** | `25% 〜 65%`（低コントラスト） | 低彩度（空気遠近） | キャラクターと競合する高彩度色・最暗色を避ける |
| **地形（Ground / Wall）** | `15% 〜 75%`（中コントラスト） | 低〜中彩度 | 踏める上面エッジのみ明るく際立たせる |
| **キャラクター・敵・アイテム** | `8% 〜 95%`（高コントラスト） | 中〜高彩度 | 最暗色アウトラインと高明度ハイライトで背景から分離する |
| **VFX・危険弾・重要UI** | `5% 〜 100%`（最大コントラスト） | 高彩度 | 瞬間的な視認性を最優先する |

### 3.1 共通ベース・無彩色・肌ランプ
| ランプ名 | キー接頭辞 | Highlight (光) | Base (基本) | Shadow 1 (1影) | Shadow 2 / Outline | 用途 |
| :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **ニュートラル白〜灰** | `neutral` | `#FFFFFF` | `#DCE3F0` | `#94A1B8` | `#525E75` | 白布、銀髪、石材明部 |
