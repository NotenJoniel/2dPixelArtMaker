## 2. 視認性・当たり判定の視覚ルール（Collision Readability）

プレイヤーが「どこに乗れて」「どれが背景の飾りか」を迷わないための必須ルールです。

| 要素区分 | 主線・エッジ処理 | 明度・彩度方針 | 例 |
| :--- | :--- | :--- | :--- |
| **通行不可の地面・壁（Solid）** | 上端（踏む面）に高明度ハイライト＋直下に濃い影を入れる | 中〜高コントラスト | 草付きの土ブロック、石レンガ床 |
| **すり抜け足場（One-Way Platform）** | 上面のみ強調し、下端は薄く抜く（厚み 4〜6px 程度） | 中コントラスト | 木の足場、石の張り出し棚 |
| **ダメージ地形（Hazard）** | 高彩度の警戒色（赤・紫・白発光）でエッジを際立たせる | 最高コントラスト | トゲ床、溶岩、毒沼 |
| **背景装飾壁（Back Wall / Non-solid）** | 主線なし、明度幅を狭く抑える | 低彩度・低コントラスト | 奥の石壁、背景の柱・ツタ |

## 3. タイルセット構成リスト（`tilesets/`）

<!-- コード描画でグリッド状に並べて1枚のタイルセットPNGとして出力します -->

| タイルグループ名 | グリッド構成例 | 必要なタイルパターン内訳 |
| :--- | :---: | :--- |
| **メイン地面（土＋草）** | `3 x 3`（9枚基本）＋内角4枚 | 上端（左角・中央・右角）、側面（左・中フィラー・右）、下端（左角・中央・右角）、内コーナー4種 |
| **石畳・遺跡ブロック** | `3 x 3` ＋ ランダムひび割れ差分2枚 | 単調な繰り返し（タイリング感）を消すため、中央フィラーは最低2〜3パターン用意する |
| **すり抜け木製足場** | `3 x 1`（横連結） | 左端・中央ループ・右端 |
| **水・液体タイル** | `2 x 2` × `3`フレーム | 水面キラキラ波打ちアニメーション対応 |

## 4. 多重スクロール遠景背景（Parallax Backgrounds: `backgrounds/`）

| レイヤーID | ファイル名例 | サイズ (px) | 横ループ | スクロール速度比 | 描画内容と色調方針 |
| :--- | :--- | :---: | :---: | :---: | :--- |
| `00_sky` | `env_01_forest_bg_00_sky.png` | `480 x 270` | 不要/可 | `0.0`（固定） | 空のグラデーション・遠くの雲 |
| `01_far` | `env_01_forest_bg_01_far.png` | `480 x 270` | **必須** | `0.15` | 遠方の山並み・巨大樹のシルエット（最も淡く空気遠近を効かせる） |
| `02_mid` | `env_01_forest_bg_02_mid.png` | `480 x 270` | **必須** | `0.4` | 中景の木立・木漏れ日（遠景より1段階濃いが、手前キャラよりは低コントラスト） |
