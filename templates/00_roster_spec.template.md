## 記入リファレンス（役割ランク ＆ サイズ区分）

| 指定列 | 選択肢 | 意味・AIの描き分け挙動 |
| :--- | :---: | :--- |
| **役割ランク (`role`)** | `hero` | **主人公**: 最優先の視認性・白目＋瞳の目力・2層重ね着・象徴モチーフ付き |
| | `party` | **仲間・主要キャラ**: 主人公とシルエットやキーカラーが被らない固有デザイン |
| | `mob` | **モブNPC（村人・店員・一般兵）**: 主役を引き立てるため、シンプルな黒目・控えめ色数で素朴に設計 |
| | `enemy` | **一般ザコ敵**: 既存ゲームIPに酷似しない独自造形・色替え派生しやすい設計 |
| | `midboss` | **中ボス・精鋭敵**: 標準キャラより一回り大きい威圧感あるシルエット |
| | `boss` | **ボス・大ボス**: 圧倒的サイズと多階調ディテールを持つ看板エネミー |
| **サイズ区分 (`scale`)** | `S` | **小型**: スライム・小動物・妖精・子供キャラ等（`sfc_16x24` なら実寸 `10〜16px` 高） |
| | `M` | **標準（普通サイズ）**: 標準的な人間・街モブ・人型モンスター（`sfc_16x24` なら `32×32` 枠・実寸 `18〜25px` 高） |
| | `L` | **大型（約1.5倍）**: 巨漢戦士・重装将軍・オーガ・中ボス等（`sfc_16x24` なら `48×48` 枠・実寸 `28〜38px` 高） |
| | `XL` | **特大（約2倍以上）**: ドラゴン・魔王・巨大ボス等（`sfc_16x24` なら `64×64` 枠・実寸 `42〜58px` 高） |
