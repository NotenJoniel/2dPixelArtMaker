## 1. 【必須項目】最初に必ず決める根幹6項目
※後から変更すると全アセットの作り直しになるため、最初に方針を決定します。

### Q1. ゲームジャンルとカメラ視点（1つ選択）
- [ ] **サイドビュー（横視点）** — 横スクロールアクション、メトロイドヴァニア、格闘など
- [ ] **トップダウン 3/4（見下ろし視点・4方向）** — 王道RPG、ローグライク、牧場・生活系など
- [ ] **クォータービュー / アイソメトリック（斜め見下ろし 2:1）** — タクティカルRPG、街づくりなど
- [ ] **フロントビュー（正面一枚絵メイン）** — コマンドバトルRPGの敵グラ、ノベル・ADVなど
- **ジャンル補足メモ**: `[例: 見下ろし型の王道ファンタジーRPG]`

### Q2. 世界観・モチーフ
- **世界観・時代モチーフ**: `[例: 剣と魔法の王道ファンタジー / 古代遺跡×蒸気機関 / サイバーパンク]`

### Q3. キャラクターのサイズ・世代規格（`size_preset` — 1つ選択）
- [ ] **`fc_16x16`：ファミコン（8-bit）風サイズ** — キャンバス `16×16` px（本体 `16×16` px、3〜4色、超レトロ・記号的）
- [ ] **`sfc_16x24`：スーファミ（16-bit JRPG）風サイズ【標準推奨】** — キャンバス `32×32` px（本体 `16×24` px 標準2.5頭身 または `16×20` px 2頭身SD、ドラクエ・FF黄金比）
- [ ] **`hd2d_18x32`：モダンJRPG（HD-2D / オクトラ）風サイズ** — キャンバス `48×48` px（本体 `18×32` px、色トレス主線・多階調グラデ）
- [ ] **`high_32x56`：ハイレゾ等身（GBA・DS / 5頭身アクション）風サイズ** — キャンバス `64×64` px（本体 `28×54` px、5頭身リアル系・多関節ボーン向き）

### Q4. デザインテイスト・雰囲気（`taste_preset` — 1つ選択）
- [ ] **`cute`：かわいい系** — クリッとした縦長目、ぴょこ毛外ハネ、Aラインシルエット、明るくポップな愛嬌重視
- [ ] **`cool`：かっこいい系** — 白目＋濃瞳の精悍な目元、非対称ツンツン毛束、細腰くびれ＋V字衣装の王道ヒロイック重視
- [ ] **`retro_classic`：レトロ王道系** — パキッとした主線と少ない色数、片足出し待機ポーズなど当時のゲームらしさ重視
- [ ] **`dark_serious`：ダーク・シリアス系** — 彩度を抑えた重厚な陰影・リムライト・色トレスによる硬派な雰囲気重視

### Q5. パーツ分割・アニメーション方針（1つ選択）
- [ ] **単一コマ打ち（4方向・歩行等を1枚絵ずつ描画 — `fc_16x16` / `sfc_16x24` に最適）**
- [ ] **簡易レイヤー分割（頭・表情・体・マント・武器の3〜6層で着せ替え・差分対応 — `sfc_16x24` / `hd2d_18x32` 推奨）**
- [ ] **多関節ボーンリグ分割（上腕・前腕・太もも・すね等12〜22パーツ分離 — `high_32x56` 専用推奨）**

### Q6. 制作対象リスト（キャラ数・敵数・モブ／ボス・サイズ区分）の指定方法（1つ選択）
※「ざっくり数だけ決めてAIにおまかせ」か、「専用設定ファイルで1体ずつ細かく指定」かを選べます。

- [ ] **手段①-A：おまかせ最小セット（お試し試作）**
  - 主人公(`M`・普通) 1体 ＋ 小型ザコ敵(`S`) 1体 をAIが世界観に合わせて企画・制作する
- [ ] **手段①-B：おまかせ基本RPGセット（サイズ対比・モブ・ボス込み）**
  - 主人公(`M`) 1体 ＋ 仲間(`M`) 1体 ＋ 街モブNPC(`M`) 1体 ＋ ザコ敵(`S`) 1体 ＋ 大型ボス(`L` または `XL`) 1体 をAIが企画・制作する
- [ ] **手段①-C：人数・サイズ内訳だけ指定して中身はAIおまかせ**
  - **味方メイン (`hero` / `party`)**: `[例: 普通M 2体、大型L 1体]`
  - **街モブNPC (`mob`)**: `[例: 普通M 1体]`
  - **ザコ敵 (`enemy`)**: `[例: 小型S 2体、普通M 1体]`
  - **中ボス・大ボス (`midboss` / `boss`)**: `[例: 大型L 1体、特大XL 1体]`
  - **アイテム・タイル等**: `[例: 武器アイコン 1点]`
- [ ] **手段②：専用設定ファイル `docs/00_roster_spec.md` で細かく個別指定する**
  - `templates/00_roster_spec.template.md` を `docs/00_roster_spec.md` にコピーして記載した個別リスト（名前・役割ランク・サイズ区分 `S/M/L/XL`・外見指定）に従って制作する
